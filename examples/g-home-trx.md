# Example G (woman, home, suspension trainer, no pullup bar, no barbell)

Profile: woman training at home with dumbbells, a bench, a suspension trainer (TRX) and bands. No barbell and no pullup bar. 3 letters.

Plan:
- A: Rear Foot Elevated Split Squat, Sissy Squats, Assisted Single Leg Deadlift, TRX Fallouts, TRX Anti Rotation Press
- B: Incline DB Bench Press, Flat Dumbbell Flys, Single Arm DB Shoulder Press, TRX Triceps Extensions, Seated Lateral Raises
- C: Dumbbell Chest Supported Rows, Dumbbell Single Arm Rows, Seated Band Pulldowns, TRX High Rows, Seated Dumbbell Curls

Why:
- Legs and abs share letter A. It is the only way to fit it into a 3 letter plan ([section 2](../programming/02-letters-and-schedule.md)).
- An assisted single leg deadlift replaces the hip thrust and leg curl: TRX leg curls are too hard for this person, and there is no barbell for a hip thrust ([section 8](../programming/08-choosing-the-movement.md), Glutes and hamstrings).
- Band pulldowns fill the vertical pull because this person will never get a pullup bar. It is a poor substitute, accepted only in a case like this ([section 8](../programming/08-choosing-the-movement.md), Back).
- One triceps movement while chest has two: adding a second triceps movement and taking out the fly is a wash, so either is acceptable on a short letter ([section 7](../programming/07-movements-per-muscle.md)).
- A suspension trainer is a better choice than a few dumbbells or bands, because progress can be graded inch by inch. The strap length and where the person stands must be tracked accurately for each exercise (introduction of [programming.md](../programming/00-intro.md)).
