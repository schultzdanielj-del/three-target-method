# Worked examples

These are base plans that show how the programming rules turn into a real set of letters. Each is a generic profile, with no names. Every reason below is one the method gives for that choice. Where no reason is given for a choice, the plan is shown and nothing is claimed about it. Section numbers refer to [programming.md](../programming/00-intro.md). Exercise names only are shown, in the order they appear in the plan.
