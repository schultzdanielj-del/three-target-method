# 11. Order inside a workout

- Compounds first. This is needed. Rarely, an isolation goes first because the person cannot make the compound heavy enough for them, so they do not need as much load to stimulate the muscle.
- Never vertical press before horizontal. It feels terrible. Horizontal then vertical is fine.
- Biceps before triceps does not matter.
- Spine loaded back movements are less ideal. Perform them later in the session if possible, so the core musculature is fresh but the back musculature is fatigued, which means they do not need as much weight. If the person has lower back issues, avoid them completely, because there will be too much focus on back health and positioning and not enough focus on intensity of contraction.
- Abs and calves float (see [sections 8](08-choosing-the-movement.md) and [10](10-calves.md)).
- Sissy squats go last on the leg letter. The knees need to be warmed up, and being pre-fatigued means you use less load, so the knees do not blow up.
- Fly movements are easy to cheat, so the second chest movement is often a decline dumbbell bench instead.
